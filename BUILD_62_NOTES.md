Build 62: Alert fixes. (1) Crash on tapping a notification fixed — UNUserNotificationCenterDelegate now uses the completion-handler methods and does all work on the main thread (the async versions completed on a background thread, after which UIKit asserted in _updateSnapshotAndStateRestorationWithAction). (2) Reliable delivery — reschedule builds all requests first, removes only stale identifiers and replaces the rest, runs are serialized, and on iOS a background task lets it finish when the app is left.
